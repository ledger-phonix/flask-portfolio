# Personal Portfolio Website

A responsive, dynamic personal portfolio website built using Python, Flask, HTML, javscript and Taiwind CSS. This project showcases my work as a Web Developer, Data Analyst, and AI-Assisted Engineer, featuring clean code separation, smooth UI interactions, and robust backend capabilities.

---

## 🚀 Features

* **Dynamic Hero Section:** Integrated with a smooth JavaScript typewriter effect highlighting core professional roles and a custom responsive grid.
* **Interactive Certificate Slider:** Responsive slider showcasing technical credentials with a clean layout customized for all screen widths.
* **Modern Minimalist Footer:** Slim, smart, and content-optimized layout.
* **Fully Responsive UI:** Styled with a blend of custom CSS variables and utility classes, optimized to cleanly hide complex desktop elements on mobile screens (below 645px) without crashing the layout.
* **Flask Backend:** Dynamic routing, clean project structure, and modular codebase.

---

## 🛠️ Tech Stack

* **Backend:** Python, Flask
* **Frontend:** HTML5, Tailwind CSS (Variables & Media Queries), JavaScript 
* **Icons & Fonts:** Font Awesome, Google Fonts
* **Version Control:** Git & GitHub
